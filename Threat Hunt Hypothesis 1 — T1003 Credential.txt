# Hunt Hypothesis — T1003 Credential Dumping via LSASS

**Date:** 2024-01-15
**Analyst:** Shuhaib
**MITRE Technique:** T1003.001 — OS Credential Dumping: LSASS Memory

## Hypothesis
An attacker with local admin access may have dumped credentials from
LSASS memory using tools like Mimikatz or ProcDump. This would be
visible as an unexpected process opening a handle to lsass.exe with
memory-read permissions.

## Data Source
- Sysmon Event ID 10 (ProcessAccess)
- Windows Security Event ID 4656 (Handle to object requested)

## Detection Logic
Look for SourceImage processes accessing TargetImage=lsass.exe
where SourceImage is NOT a known legitimate system process,
particularly with GrantedAccess values of 0x1010 or 0x1FFFFF.

## False Positive Sources
- Windows Defender (MsMpEng.exe)
- svchost.exe, lsm.exe, csrss.exe, wininit.exe

## Escalation Criteria
True Positive if:
- SourceImage is from a temp/user-writable directory
- GrantedAccess = 0x1FFFFF (full access)
- CallTrace references unknown or unsigned DLLs
